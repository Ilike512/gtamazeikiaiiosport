# Mažeikiai map data

`mazeikiai.json` is a projected, filtered derivative database of OpenStreetMap. Its data are © OpenStreetMap contributors, licensed under the [Open Data Commons Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). [OpenStreetMap copyright and attribution](https://www.openstreetmap.org/copyright)

The Mažeikiai-area extract was retrieved from the OpenStreetMap public Map API on 2026-11-21. Coordinates are stored as local metres east and south of the WGS84 origin **56.3066° N, 22.3320° E**. The source request was split into 12 overlapping-edge tiles with these boundaries.

- Longitude boundaries in degrees east: 22.278, 22.316, 22.354, 22.392.
- Latitude boundaries in degrees north: 56.286, 56.300, 56.314, 56.328, 56.342.

Two additional extracts cover Kruciai and Tirkšliai, with a southern extension to the height grid blended into the existing terrain. [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) · [Mapzen Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)

The source API returns whole ways crossing a tile edge, so some geometry extends past the request bounds. The build script deduplicates ways and nodes by OpenStreetMap ID and includes supported roads, building footprints, selected land-use polygons, railway, crossings, water and parking. It converts the coordinates to metres and estimates missing road widths and building heights. The imported map omits interiors and surveyed elevation.

To regenerate from downloaded OSM 0.6 XML tile files, run `node tools/build_city.mjs <folder-with-osm-tiles>` from the project. The project uses the bundled JSON at runtime. Map attribution also appears on the in-game minimap.
# Supplemental cadastral buildings

`grpk_buildings.json` contains 1,722 additional footprints from the Lithuanian Georeferenced Base Cadastre, GRPK © Lietuvos Respublikos aplinkos ministerija, geoportal.lt. Coordinates were projected to the game's metre grid. The importer omits features that overlap an existing building or have vertices too close to a mapped street. The latest pass recovers seven more small detached buildings. Building heights are estimated. [GRPK open data, CC BY 4.0](https://data.gov.lt/datasets/3424/) · [Published building layer](https://www.geoportal.lt/arcgis/rest/services/NZT/GRPK/MapServer/22)

`grpk_streets.json` contains 356 additional sections of streets, service roads and paths. The importer filters out near-parallel duplicates and candidates crossing building footprints. The latest pass recovers side routes and footpaths that were previously filtered out beside streets. `river_corridor.json` adds surveyed outlines for the Venta, Jautakių, Kalnėnų II and Stadiono waters. Surface heights and riverbed depth are estimated for gameplay. [GRPK roads](https://www.geoportal.lt/arcgis/rest/services/NZT/GRPK/MapServer/11) · [GRPK water](https://www.geoportal.lt/arcgis/rest/services/NZT/GRPK/MapServer/19)

## Parks and storefronts

- The original OpenStreetMap tiles also provide the 99 mapped barrier ways, gate positions, path surface tags and mapped park fixtures in this build. Gate gaps stay open in the rendered and collision geometry. The game uses tagged bridge segments to supply a continuous collision deck. [OpenStreetMap attribution](https://www.openstreetmap.org/copyright)
- The northwest expansion includes the mapped roads and building footprints for Kalnėnai, Troškučiai, Tulnikiai and Griežė. The new terrain extends the existing 23 m grid using Terrarium elevation tiles. `tools/extend_northwest_elevation.ps1` reproduces the northwestern extension using Terrarium z12 tiles 2299–2302 by 1266–1270. [OpenStreetMap](https://www.openstreetmap.org/copyright) · [Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)
- The Žemaitijos g. shopping complex has Maxima XX in the main blue-and-white frontage and the bar and bank to its right. The separate Maxima on M. Daukšos g. 26 occupies the mapped corner complex near Lidl. [Maxima store directory](https://www.maxima.lt/parduotuves)
- Geležinkelio g. uses the supplied Street View references for the parked tanker wagons, grass verge and alternating rail fence and sound barrier. The wagons sit on a mapped siding.
- Swift Arena uses its mapped footprint and the supplied Street View reference for the dark ribbed cladding. Lidl at M. Daukšos g. 24 and Senukai at Tirkšlių g. 5E use mapped building outlines, with original playable layouts. - Sodų skveras uses the published playground photographs and site plan. Senamiesčio Park takes its gabion entrance and woodland layout from municipal photos. Melioratorių and Juodpelkio include photo-based play equipment, benches and path lighting. Vyturių takas and Pavenčių are marked and furnished along their mapped walks. The municipal tree inventory locates Senjorų Park’s cherry grove and Pavasario Square.
