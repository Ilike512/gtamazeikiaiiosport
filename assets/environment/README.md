# Photographic environment textures

These photographs were downloaded from Poly Haven and are available under the [CC0 1.0 public domain dedication](https://creativecommons.org/publicdomain/zero/1.0/).

- `sky.hdr` is the 2K HDR of [Kloppenheim 05 (Pure Sky)](https://polyhaven.com/a/kloppenheim_05_puresky) by Greg Zaal and Jarod Guest.
- `asphalt.jpg` is the 1K diffuse map of [Asphalt 01](https://polyhaven.com/a/asphalt_01) by Charlotte Baglioni and Dario Barresi.
- `turf.jpg` is the 1K diffuse map of [Leafy Grass](https://polyhaven.com/a/leafy_grass).
